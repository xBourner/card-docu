# Customization

All options are optional – without any setting the card shows today's events of all
your calendars.

<img class="doc-img-responsive" src="https://raw.githubusercontent.com/xBourner/calendar-card-plus/main/.github/images/calendar-card-plus.png" alt="Calendar Card Plus Preview">

---

## Features

| Feature | Description |
|---------|-------------|
| [Time Window](time-window.md) | How far ahead the card looks, empty days |
| [Layout](layout.md) | Compact or unfolded view, grouping, divider, max. events |
| [Text & Visibility](text-visibility.md) | Date, time, duration, location, weekday and month |
| [Calendars & Colors](calendars.md) | Hide calendars, read only calendars and colors per calendar |
| [Events & Popup](events-popup.md) | Popup with all events, add, edit and delete events |
