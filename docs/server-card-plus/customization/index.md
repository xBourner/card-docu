# Customization

All options are optional – without any setting the card shows the first detected
system in the classic design.

---

## Features

| Feature | Description |
|---------|-------------|
| [Designs](designs.md) | Classic bars, circles or rack LED segments |
| [Thresholds & Colors](thresholds-colors.md) | Warning and critical levels and their colors |
| [Disk Temperatures](disk-temperatures.md) | Every host disk as its own bar or ring |
| [Controls](controls.md) | Start, reboot, shut down and stop buttons |
| [Dashboard Mode](dashboard-mode.md) | All systems as a grid, with hiding and per-system overrides |
