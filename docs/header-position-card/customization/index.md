# Customization

The card has only a few options – the editor shows all of them.

!!! info "Background card"
    The card is not rendered on your dashboard. It only appears in edit mode and
    applies its styles to the dashboard header in the background.

---

## Features

| Feature | Description |
|---------|-------------|
| [Design](design.md) | Default bar at the bottom or a minimal floating pill |
| [Breakpoints](breakpoints.md) | Screen sizes where the header moves to the bottom |
| [Global Mode](global-mode.md) | Apply the position to every dashboard |
| [Behaviour](behaviour.md) | Padding, safe areas and reset |
