# Customization

All customization options are optional – choosing an area is enough for a working
card. Each feature has its own section in the editor.

!!! info "Info"
    Some customization combinations may break due to Home Assistant updates. Test one
    option at a time if unsure.

<img class="doc-img-responsive" src="https://raw.githubusercontent.com/xbourner/area-card-plus/main/.github/img/area-multi-light-v2.png" alt="Area Card Plus Preview">

---

## Features

| Feature | Description |
|---------|-------------|
| [Appearance](appearance.md) | Name, icon, display type, layout, V1/V2 design and theme |
| [Camera](camera.md) | Show a camera snapshot or live view in the card |
| [Actions](actions.md) | Tap, double tap and hold action of the card |
| [Domains](domains.md) | Toggle buttons per domain (light, switch, fan, climate …) |
| [Alerts, Covers & Sensors](device-class-items.md) | Items per device class – alert chips, cover buttons, sensor values |
| [Custom Buttons](custom-buttons.md) | Your own buttons for any entity, placed anywhere on the card |
| [Popup / Dialog](popup-dialog.md) | Popup with tile cards, domain filters and extra entities |
| [Visibility](visibility.md) | Hide or exclude entities and filter entity categories |
| [Styles](styles.md) | Custom CSS and animations |
