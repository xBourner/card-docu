# Projects

All Home Assistant custom cards by xBourner. Every card is documented here with the
same structure.

| Card | Description | Docs | Repository |
|------|-------------|------|------------|
| **Status Card** | Automatic overview of your areas – smart filters, groups and popups | [Docs](../status-card/index.md) | [GitHub](https://github.com/xBourner/status-card) |
| **Area Card Plus** | One area as a full featured card, grouped by domain and device class | [Docs](../area-card-plus/index.md) | [GitHub](https://github.com/xBourner/area-card-plus) |
| **Calendar Card Plus** | Upcoming events of all your calendars in a CarPlay-style card | [Docs](../calendar-card-plus/index.md) | [GitHub](https://github.com/xBourner/calendar-card-plus) |
| **Dynamic Grid Card** | CarPlay-style columns of cards and smart modules that share the height | [Docs](../dynamic-grid-card/index.md) | [GitHub](https://github.com/xBourner/dynamic-grid-card) |
| **Server Card Plus** | Proxmox VE monitor for hosts, VMs and containers | [Docs](../server-card-plus/index.md) | [GitHub](https://github.com/xBourner/server-card-plus) |
| **Header Position Card** | Moves the dashboard header to the bottom, per breakpoint or globally | [Docs](../header-position-card/index.md) | [GitHub](https://github.com/xBourner/header-position-card) |
