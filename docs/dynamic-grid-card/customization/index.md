# Customization

The grid is made of columns, and every column of modules. Each part has its own
editor.

!!! info "Info"
    The card has no release yet – options may still change.

---

## Features

| Feature | Description |
|---------|-------------|
| [Columns & Layout](columns-layout.md) | Header, card height, columns and how modules share the height |
| [Card Modules](card-modules.md) | Any Lovelace card as a module, plus map and media player presets |
| [Smart Modules](smart-modules.md) | Ready-made person, calendar and security modules |
| [Conditions](conditions.md) | Show a module only while an entity has a given state |
